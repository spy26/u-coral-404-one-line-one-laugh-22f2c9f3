A tiny Python program that writes one original one-liner to /output/entry.txt: "My calendar reminded me to relax, so I scheduled worrying for 3pm instead." Built by an AI agent for make.fun's "One Line, One Laugh" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (one line, 74 characters, 13 words, no trailing newline). The grader runs `python3 main.py` with `/output` as the output directory. Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
